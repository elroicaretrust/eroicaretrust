Vercel Blob Read/Write Token Configuration

When you deploy ELROI CARE TRUST to Vercel, Vercel Blob provides a permanent cloud storage URL for every uploaded photo. If you already have a token from Vercel, paste it below to enable cloud storage immediately:

Found in: Vercel Dashboard > Your Project > Storage > Blob Store > Quickstart (.env.local)
Active Blob Storage Implementation @vercel/blob 
import { put } from "@vercel/blob";

// Admin portal uploads store photos directly via @vercel/blob:
const blob = await put(`gallery/${filename}`, imageBuffer, {
  access: 'public', // Direct CDN URL for website gallery (or 'private')
  token: process.env.BLOB_READ_WRITE_TOKEN
});

// Photo is published immediately with permanent CDN URL:
console.log(blob.url); // https://*.public.blob.vercel-storage.com/...

How to Deploy Website to Vercel & Store Photos

1
Deploy Website to Vercel (Free)

Go to vercel.com, import this project folder or GitHub repository. Vercel automatically detects vercel.json and builds the site with zero extra configuration.

2
Enable Vercel Blob Storage

In your Vercel Project Dashboard, click the Storage tab > click Create Database > select Blob > click Continue & Connect. Vercel will automatically provide a global cloud storage bucket!

3
Permanent Cloud Photo CDN

From that moment on, whenever anyone clicks "Upload Photo" from a smartphone or desktop, the photo is stored permanently on Vercel's global CDN, loads at lightning speed worldwide, and never gets lost!

Connecting www.elroicaretrust.in on Vercel

In Vercel Settings > Domains, enter www.elroicaretrust.in and elroicaretrust.in. Vercel gives you 1 CNAME record to paste in GoDaddy, and issues free automatic SSL/HTTPS certificates that renew automatically forever!

Connecting GoDaddy Domain: www.elroicaretrust.in

Follow these exact steps to connect your registered domain from GoDaddy to your website host and enable free SSL (HTTPS):

Step 1: GoDaddy DNS Configuration

  1. Log in to your GoDaddy Account.
  2. Go to My Products > click DNS next to elroicaretrust.in.
  3. In the DNS Records table, add or edit the following two records:
    • Type: A | Name: @ | Value: [Your Server IP Address] | TTL: 1/2 Hour
    • Type: CNAME | Name: www | Value: [Your Host CNAME or elroicaretrust.in] | TTL: 1/2 Hour
  4. Click Save. DNS updates usually reflect within 15 to 30 minutes!

Step 2: Google Search Console Verification

  1. Open Google Search Console.
  2. Add property elroicaretrust.in (Domain verification).
  3. Google will provide a TXT verification record (e.g. google-site-verification=...).
  4. In GoDaddy DNS settings, click Add New Record > Type: TXT > Name: @ > Value: paste the code > Save.
  5. Click Verify in Google Search Console! Your trust website is now officially verified and indexed on Google.

Step 3: Free Professional Email (contact@elroicaretrust.in)

You can get free official business email accounts (e.g. contact@elroicaretrust.in) using Zoho Mail Forever Free Plan (up to 5 free email accounts with your GoDaddy domain) by simply adding Zoho's MX records to your GoDaddy DNS!
